# AI 整蛊解压机 🎮

四位虚构 AI 员工的卡通恶搞游戏，12 种玩具道具，带音乐与漫画特效。所有代码和人物贴图包含在 `index.html` 内，可离线游玩，不需要 API Key。

- 在线游戏（GitHub Pages 已启用时）：https://hzp15abc-collab.github.io/my-first-website/ai-prank-kingdom/
- 轻量模式：https://hzp15abc-collab.github.io/my-first-website/ai-prank-kingdom/lite.html
- 主入口：`index.html`（优先 WebGL 3D，自动回退 2.5D）
- 轻量入口：`lite.html`（不需要 WebGL）
- 手机上可点击四位员工的头像切换角色，选择道具后点「整蛊一下」。
- 纯属娱乐，非 Grok、OpenAI、Anthropic 或 DeepSeek 官方产品。

这套游戏位于单独目录，不影响仓库根目录现有网站与其他游戏。
