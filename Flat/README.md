# Flat · 灵魂头打飞机

手机竖屏 Canvas 射击小游戏。图 1 是灵魂头；图 2 是南沙仔（广州南沙）。

游戏网址：https://hzp15abc-collab.github.io/my-first-website/Flat/

## 操作

手指拖动战机，自动连射；点击「爆发」清屏。首页可直接挑战 Boss。
点击「开始打飞机」后启用电子 diu 音效，可随时静音。
电脑支持方向键 / WASD 移动、空格爆发、P / Esc 暂停。

## 部署与素材

本项目位于 Flat/，使用现有 main 分支的 GitHub Pages 发布，不修改仓库首页或其他游戏目录。
index.html、style.css、game.js 与两张 WebP 照片均在同一目录，无第三方 CDN、API 或统计脚本。
人物照片由用户提供的原图裁切，并保留照片尺寸与五官比例；只进行网页用 WebP 编码压缩，没有重新生成、修饰、拉伸五官。

## 打开方式

请用 Safari 等支持 JavaScript 的浏览器打开上面的 HTTPS 网址，不要在微信或「文件」中预览 .html 附件。
页面提供初始化错误、照片读取失败与启动超时提示，避免一直停留在「角色载入中」。
音效需要用户点击后才能开启，不依赖下载音频。

这是用户已确认发布的公开仓库与网页，人物照片可公开访问。noindex 只是搜索引擎提示，不是访问控制。

## 验证范围

发布前通过 Chromium 390×735 手机尺寸模拟测试：角色载入、开始、暂停恢复与 Boss 模式，无脚本错误。
此记录不代表真实 iPhone、Safari 或微信实机验证。
