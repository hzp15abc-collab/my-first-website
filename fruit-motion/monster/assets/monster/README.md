# V2.0 R2 isolation material

The 20 PNG sprites are original generated toy-style fantasy figures. No television stills, branded costume assets or external images are packaged. The visual reference is a style direction only. The individual file identities are pinned in `art/manifest.json`.

The 28 WAV clips are original synthesized short toy effects (14 appearances and 14 defeats); see `audio/manifest.json` for per-clip provenance and hashes. They are not copied film, game or commercial recordings. Hero phrases are original Cantonese text; voice playback is device-local and conditional on a supported Cantonese voice. Actual voice must be verified; captions do not pass that requirement.

The requested Eason Chan theme song is not included. The original licensed V1.7 music library remains untouched. This candidate’s default monster music may use the licensed Virtual Rush recording (see root THIRD_PARTY.md); personal audio is only selected and played locally by the user and never packaged or uploaded.

Private experimental candidate; not a production or release approval.
